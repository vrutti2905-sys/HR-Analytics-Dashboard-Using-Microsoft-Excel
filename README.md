# HR Analytics Dashboard — Excel

## Project Overview
This project presents an HR Analytics Dashboard built using Microsoft Excel to analyze employee data, attrition, demographics, education, and job roles. The dashboard provides a visual overview of workforce patterns to support HR analysis and decision-making.

## Key Performance Indicators (KPIs)
- **Total Employees:** 1,470
- **Attrition:** 237
- **Active Employees:** 1,233
- **Attrition Rate:** 16.12%
- **Average Age:** 37 years
- **Job Satisfaction Rating:** 2.6

## Dashboard Visualizations
The dashboard includes the following charts and visualizations:

- **Total Employees by Gender:** Compares employee counts by gender.
- **Education-Wise Attrition:** Displays attrition counts across education levels.
- **Attrition by Job Role:** Compares attrition across different job roles.
- **Department-Wise Attrition:** Shows the distribution of attrition across HR, R&D, and Sales.
- **Attrition by Age Group:** Compares attrition across different age categories.
- **Attrition by Marital Status:** Displays attrition counts for married, single, and divorced employees.

## Interactive Filters
The dashboard includes filters for:
- Education Field
- Department
- Gender

These filters help users explore employee data across different categories.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and interactive filters
- Excel data visualization

## Project Objectives
- Analyze employee attrition patterns.
- Compare workforce demographics by gender and age.
- Understand attrition across departments, education levels, and job roles.
- Explore relationships between marital status and attrition.
- Present key HR metrics in a single dashboard.

## Key Takeaways
This project demonstrates how Microsoft Excel can be used to organize HR data, create interactive visualizations, and present workforce insights in a clear and structured format.

## Conclusion
The HR Analytics Dashboard provides a consolidated view of important employee metrics. It helps users explore workforce trends and identify areas that may require further investigation to support employee retention and HR planning.
